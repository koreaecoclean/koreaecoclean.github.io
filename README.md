# 코리아 에코크린 공식 홈페이지

사무실·병원·상가·헬스장 정기청소 전문업체 **코리아 에코크린(Korea Eco Clean)** 의 공식 홈페이지입니다.

- 주소: <https://koreaecoclean.github.io>
- 호스팅: GitHub Pages (`main` 브랜치 루트)

## 구성

```
index.html            메인 페이지 (히어로 영상·회사 소개·연혁·자격증·서비스·차별성·현장 영상/사진·지역·FAQ·예약 상담·이벤트)
styles.css            스타일시트 (화이트/소프트그레이 + 딥그린, 스크롤 등장 애니메이션)
script.js             인터랙션 (스크롤 진행 바·등장 애니메이션·카운트업·사진 필터/라이트박스·자격증 확대·히어로/현장 영상 재생·예약 폼)
404.html              없는 페이지 안내
robots.txt            검색 로봇 정책 + sitemap 위치
sitemap.xml           사이트맵
manifest.webmanifest  모바일 웹앱 정보
assets/
  logo.png            로고 원본 (헤더·푸터·파비콘)
  ceo-profile.jpg     대표 프로필 (회사 소개)
  hero.jpg            이전 버전 첫 화면 사진 (현재 미사용, 보관)
  about.jpg           이전 버전 회사 소개 사진 (현재 미사용, 보관)
  og-image.jpg        카카오톡·SNS 공유 미리보기 (1200×630)
  videos/             현장 영상 (field-hero.mp4 = 히어로 배경, field-1~3.mp4 = 현장 영상 섹션, poster-*.jpg)
  certs/              자격증 사본 4장 (생년월일 가림 처리)
  photos/             현장 사진 (7장)
  icon-192/512.png    앱 아이콘
```

## 수정 방법

1. 내용은 `index.html`, 디자인은 `styles.css`, 동작은 `script.js`에서 고칩니다.
2. 사진을 바꾸려면 `assets/photos/`의 파일을 같은 이름으로 교체합니다.
3. `git add -A && git commit -m "..." && git push` 하면 1~2분 뒤 사이트에 반영됩니다.
4. CSS·JS·영상을 고친 뒤에는 `index.html`의 `?v=` 버전 값(예: `styles.css?v=20261124i`)도 함께 올려 브라우저 캐시를 갱신합니다.
5. 예약 상담 폼은 정적 페이지라 서버 저장 없이, 입력 내용을 문자(`sms:`)·전화(`tel:`)·복사로 넘기는 방식입니다.
6. 자격증 이미지를 새로 넣을 때는 생년월일 부분을 반드시 가림 처리한 사본을 `assets/certs/`에 넣습니다.
